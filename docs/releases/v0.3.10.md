Autark-Plus 0.3.10 is the first release from [desquerteur/Autark-Plus](https://github.com/desquerteur/Autark-Plus), Noriel's standalone build of Autark. It is based on [Autark / OpenAutark by Teydra Lab](https://github.com/teydra/OpenAutark) (Apache-2.0). The number skips 0.3.9 because the original Autark already uses it.

An installed 0.3.8 finds this release by itself through Settings › Updates.

## New

- **Schedules** ([#20](https://github.com/desquerteur/Autark-Plus/issues/20)): a sidebar entry (and phone tab) for timed agent jobs, messages and reminders. You can write rules in plain words ("every first Monday of the month"), see the next runs and a run history, and pause, run now, duplicate, edit or delete a schedule.
- **Report issue → GitHub:** a feedback report can be filed as an issue in desquerteur/Autark-Plus straight from the app.
- **Dictation can send by itself** ([#18](https://github.com/desquerteur/Autark-Plus/issues/18)).
- **One browser button in the title row:** inside a chat the globe opens that chat's tabs; elsewhere it opens the global pane. Only one browser is open at a time.
- **Projects:** a hired agent's empty 1:1 no longer shows up as an "Untitled session" under its project.

## Fixed

- **Windows update helper** ([#1](https://github.com/desquerteur/Autark-Plus/issues/1)): installing an update no longer opens console windows, and the helper always exits.
- **Agents posting as the person** ([#2](https://github.com/desquerteur/Autark-Plus/issues/2)): `shell.exec` no longer passes on an agent token the runtime inherited.
- **Feedback service** ([#21](https://github.com/desquerteur/Autark-Plus/issues/21)): the missing `FEEDBACK_IMAGE_LIMIT` and `FeedbackSubmission` are now defined in the contract, so the service builds again.
- **Node 26 media calls** ([#22](https://github.com/desquerteur/Autark-Plus/issues/22)): long media and video generation calls keep their 10-minute socket timeouts again.
- **Settings › Updates** ([#23](https://github.com/desquerteur/Autark-Plus/issues/23)): the hint now gives the real check intervals: every minute while the window is open, every 15 minutes from the tray.
- **Dependencies:** fixes for the Dependabot alerts in minimatch (ReDoS) and undici.

## Known open issues

- [#24](https://github.com/desquerteur/Autark-Plus/issues/24) Gemini "Sign in with Google" can stay stuck on "Installing Gemini CLI…".
- [#25](https://github.com/desquerteur/Autark-Plus/issues/25) The "5-hour limit" bar is empty when the provider reports no data.
- [#26](https://github.com/desquerteur/Autark-Plus/issues/26) The Fusion connector logs an error at every start while Fusion 360 isn't running.
- [#27](https://github.com/desquerteur/Autark-Plus/issues/27) 22 Electron window tests fail on the release PC. These are test-only failures.

## Build

This release was built locally on the release PC with `scripts/release/release-all.ps1` from commit 5aee00c, because GitHub Actions is unavailable on this account. It includes the Windows x64 installer, Linux x64 and arm64 builds (tar.gz for the headless install, AppImage, deb) and the signed Android APK. The Windows installer isn't code-signed.
