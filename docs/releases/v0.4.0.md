Autark-Plus 0.4.0 is the first release with an app for every platform: Windows, macOS (Apple silicon and Intel), Linux desktop and server (x64 and arm64) and Android. A 0.3.10 or 0.3.11 installation updates to it by itself through Settings › Updates.

## Downloads

| Platform | File |
|---|---|
| Windows 10/11 (x64) | `autark-windows-x64.exe` |
| macOS, Apple silicon (M1 and later) | `autark-mac-arm64.zip` |
| macOS, Intel | `autark-mac-x64.zip` |
| Linux desktop (x64) | `autark-linux-x64.AppImage` |
| Debian/Ubuntu desktop | `autark-linux-amd64.deb`, `autark-linux-arm64.deb` |
| Linux server, headless (x64 / arm64) | `autark-linux-x64.tar.gz`, `autark-linux-arm64.tar.gz` – installed by `scripts/install-headless.sh` |
| Android | `autark-android.apk` (signed) |

SHA-256 checksums of every file are in `SHA256SUMS.txt`; `release.json` names the build commit.

## New

- **macOS app** for Apple silicon and Intel. It is ad-hoc signed and not notarized by Apple: the first start is refused once – System Settings › Privacy & Security › **Open Anyway** (on macOS 14 and older: right-click › Open). If macOS calls the app "damaged", run `xattr -dr com.apple.quarantine /Applications/Autark.app` once. Details in the README under Installing.
- **App-wide scale setting** ([#30](https://github.com/desquerteur/Autark-Plus/issues/30)): Settings › Appearance scales the whole interface from 80 to 150 %, separately for PCs and phones, also with Ctrl +/−/0. The setting is kept across restarts.
- **Grok** ([#28](https://github.com/desquerteur/Autark-Plus/issues/28)): Grok Build plan accounts and current Grok models.

## Fixed

- **Update helper** ([#1](https://github.com/desquerteur/Autark-Plus/issues/1)): an app started by the update helper can update itself again (inherited update values are no longer passed on). No console window stays open after an update.
- **Gemini sign-in** ([#24](https://github.com/desquerteur/Autark-Plus/issues/24)): the plan sign-in no longer hangs on "Installing…", and Google's refusal of a personal account is shown to you.
- **Models › 5-hour bar** ([#25](https://github.com/desquerteur/Autark-Plus/issues/25)): no empty bar for a plan that reports no 5-hour window.
- **Fusion connector** ([#26](https://github.com/desquerteur/Autark-Plus/issues/26)): a closed Fusion 360 counts as "not running", with one info line instead of a warning at every start.
- **Report issue:** a title with an unclosed bracket no longer stops a report.

## Known limits

- The macOS app is built on Linux (`scripts/release/build-mac.sh`) because no Mac or macOS CI runner is available yet. Its bundle, CPU and signature are checked, but it has not yet been started on a real Mac. Please report what you see.
- The Windows installer is not code-signed (SmartScreen: More info › Run anyway).
- [#27](https://github.com/desquerteur/Autark-Plus/issues/27): 22 Electron window tests fail on the release PC (test-only).

## Build

Built locally on the release PC with `scripts/release/release-all.ps1`. GitHub Actions is unavailable on this account; `.github/workflows/build-desktop.yml` builds the same set of files once it runs again.
