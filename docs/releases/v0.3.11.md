Autark-Plus 0.3.11 is a small fix release on top of [0.3.10](v0.3.10.md). It is also the first release that a 0.3.10 installation picks up and installs entirely by itself through Settings › Updates.

## Fixed

- **Windows update helper** ([#1](https://github.com/desquerteur/Autark-Plus/issues/1)): the helper never tries to start a missing installer. Before, Windows fell back to a visible "cannot find" dialog, and that dialog kept the helper running.
- **Release builds in a worktree:** the release script removes a linked `node_modules` before `npm ci`. Before, a build in a worktree could empty the main clone's shared `node_modules`.
- **Tests:** the device `sync-files` test polls instead of using fixed sleeps, so it no longer fails when tests run in parallel.

## Updating from 0.3.8

The update helper in 0.3.8 exits together with the app, so 0.3.8 downloads an update but never installs it ([#1](https://github.com/desquerteur/Autark-Plus/issues/1)). To get off 0.3.8, run `autark-windows-x64.exe` from this release once by hand. From 0.3.10 on, updates install by themselves.

## Known open issues

- [#24](https://github.com/desquerteur/Autark-Plus/issues/24) Gemini "Sign in with Google" can stay stuck on "Installing Gemini CLI…".
- [#25](https://github.com/desquerteur/Autark-Plus/issues/25) The "5-hour limit" bar is empty when the provider reports no data.
- [#26](https://github.com/desquerteur/Autark-Plus/issues/26) The Fusion connector logs an error at every start while Fusion 360 isn't running.
- [#27](https://github.com/desquerteur/Autark-Plus/issues/27) 22 Electron window tests fail on the release PC. These are test-only failures.

## Build

This release was built locally on the release PC with `scripts/release/release-all.ps1` (build commit in `release.json`), because GitHub Actions is unavailable on this account. It includes the Windows x64 installer, Linux x64 and arm64 builds (tar.gz for the headless install, AppImage, deb) and the signed Android APK. The Windows installer isn't code-signed. SHA256 checksums are in `SHA256SUMS.txt`.
